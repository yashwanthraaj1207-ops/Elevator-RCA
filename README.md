# 🛗 Elevator-RCA

### Intelligent Elevator Diagnostics & Root Cause Analysis Platform

**Elevator-RCA** is an interactive elevator diagnostics and Root Cause Analysis (RCA) platform designed to help maintenance technicians investigate elevator faults, understand component conditions, verify repairs, and maintain diagnostic records through a modern, immersive interface.

The project focuses on an intuitive engineering experience, combining interactive 3D visualization, fault investigation workflows, and maintenance-oriented data presentation.

---

## 🚀 Key Features

### 🛗 Interactive 3D Elevator Visualization

* Explore an elevator model in a 3D environment.
* Interact with individual elevator components.
* Inspect component information and simulated condition data.
* Visualize elevator systems through an immersive interface.

### 🔍 Fault Investigation

* Simulate elevator fault scenarios.
* Investigate potential causes of equipment failures.
* Follow a structured diagnostic workflow.
* Present relevant fault information using mock diagnostic data.

### 🔧 Repair Verification

* Simulate repair and verification workflows.
* Review the simulated condition of components after repairs.
* Track investigation progress.

### 📋 Maintenance Records

* Organize diagnostic and repair information.
* Present maintenance records through a structured interface.
* Support a consistent workflow from fault detection to repair documentation.

### 📊 Engineering Dashboard

* Display diagnostic information through a dashboard-oriented interface.
* Present component conditions and simulated system data.
* Provide an organized overview of the investigation process.

### 🌗 Modern User Interface

* Responsive and visually rich interface.
* Dark and light theme support.
* Interactive UI components and smooth navigation.

## ⚙️ Installation and Setup

### Prerequisites

Install the following before running the project:

* Node.js
* npm
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/yashwanthraaj1207-ops/Elevator-RCA.git
```

### 2. Navigate to the Project Directory

```bash
cd Elevator-RCA
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Application

Open the local URL displayed in your terminal, typically:

```text
http://localhost:5173
```

## 📁 3D Model Assets

The application can use a GLB-format elevator model for 3D visualization.

Example asset location:

```text
public/
└── models/
    └── elevator_rca.glb
```

Ensure the model exists at the expected path and that its materials, lighting, and scale are configured correctly.

## 🧪 Prototype Scope

Elevator-RCA currently focuses on the frontend experience and simulated diagnostic workflows.

Depending on the implemented version, features may use local mock data and deterministic simulations rather than live elevator telemetry or real diagnostic hardware.

**Important:** This prototype is not a certified elevator safety system and must not be used to control, repair, or certify real elevator equipment.
